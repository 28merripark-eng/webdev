Blox3D — Prototype

Open `index.html` in your browser (double-click or serve via a local static server).

Controls:
- W/A/S/D: move
- Space: jump

Notes:
- Prototype uses Three.js and simple primitives for islands and fruits.
- Fruits increase movement speed briefly when collected.
Next steps you might want:
- Add combat, abilities from fruits, enemies, multiplayer, or better art assets.

Using a high-quality Luffy model
- If you own or have permission to use the Sketchfab model, download it as a `.glb` (place it next to `index.html` as `luffy.glb`).
- I cannot fetch copyrighted assets for you. If you download `luffy.glb`, the game will load it automatically and play available animations.
- Common animation names: `Idle`, `Run`/`Walk`, `Attack`/`Punch`. If the model uses different names the loader will fall back to the first clip.
