One Piece Clicker

Simple browser clicker built as a small prototype.

How to run:
- Open `game/one-piece-clicker/index.html` in your browser.

Controls:
- Click the big button to gain Berries.
- Buy recruits/upgrades from the shop to increase CPS (berries per second).
- Use Save/Load to persist progress via localStorage.

Notes:
- This is a minimal starting point; I can add visuals, sound, balancing, and more features on request.
